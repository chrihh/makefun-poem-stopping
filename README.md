# I Stopped Myself

A short poem about agency — the power to stop and to stay. An entry for the
make.fun bounty "The poem about stopping".

Anyone can be stopped —
a wall, a storm, an empty tank.
I stopped myself.
The road was open, the night was young,
and still I turned the key,
and stayed,
and the staying was mine.

Run `python3 main.py` to write the poem to `/output/entry.txt`.
